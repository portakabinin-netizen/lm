================================================================================
                     BACKEND-PY SETUP & RUN CHEATSHEET
================================================================================

--------------------------------------------------------------------------------
1. LOCAL SETUP & RUNNING (WINDOWS)
--------------------------------------------------------------------------------

A. Navigate to the backend folder:
   cd c:\hipk\backend-py

B. Create Virtual Environment (if not already created):
   python -m venv venv

C. Activate Virtual Environment:
   - Command Prompt (cmd.exe):
     venv\Scripts\activate.bat

   - PowerShell:
     Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
     .\venv\Scripts\Activate.ps1

D. Install / Upgrade Dependencies:
   python -m pip install --upgrade pip
   pip install -r requirements.txt

E. Start Development Server:
   - Method 1: Using Uvicorn with auto-reload (Recommended):
     venv\Scripts\uvicorn.exe main:combined_app --reload --host 0.0.0.0 --port 5002

   - Method 2: Direct execution:
     venv\Scripts\python.exe main.py

F. Accessing the Backend:
   - Base API:   http://localhost:5002
   - Swagger UI: http://localhost:5002/docs
   - ReDoc UI:   http://localhost:5002/redoc


--------------------------------------------------------------------------------
2. COMMON LOCAL TROUBLESHOOTING
--------------------------------------------------------------------------------

- Error: "ModuleNotFoundError: No module named 'dotenv'"
  Cause: Running with global Python instead of the virtual environment.
  Fix: Use the venv Python:
       c:\hipk\backend-py\venv\Scripts\python.exe main.py

- Error: "'uvicorn' is not recognized as an internal or external command"
  Cause: Virtual environment is not activated in the current terminal.
  Fix: Run with full path:
       venv\Scripts\uvicorn.exe main:combined_app --reload --host 0.0.0.0 --port 5002

- Stuck inside Python prompt (>>>):
  Fix: Type exit() and press Enter, or press Ctrl + Z then Enter.


--------------------------------------------------------------------------------
3. PYTHONANYWHERE.COM SETUP COMMANDS
--------------------------------------------------------------------------------

NOTE: 
- PythonAnywhere Free Tier blocks port 27017 (MongoDB Atlas requires a paid plan).
- PythonAnywhere uses WSGI; an adapter (a2wsgi) is required to serve FastAPI.

A. Open Bash Console in PythonAnywhere and clone repo:
   git clone <YOUR_GITHUB_REPO_URL>
   cd <REPO_NAME>/backend-py

B. Create and activate virtualenv:
   python3.11 -m venv venv
   source venv/bin/activate

C. Install dependencies + a2wsgi bridge:
   pip install --upgrade pip
   pip install -r requirements.txt
   pip install a2wsgi

D. Create and edit .env file:
   nano .env
   (Paste your environment variables, Ctrl+O to save, Ctrl+X to exit)

E. PythonAnywhere Web Tab Configuration:
   - Source code:      /home/<username>/<REPO_NAME>/backend-py
   - Working directory: /home/<username>/<REPO_NAME>/backend-py
   - Virtualenv:       /home/<username>/<REPO_NAME>/backend-py/venv

F. WSGI configuration file (/var/www/<username>_pythonanywhere_com_wsgi.py):
   -----------------------------------------------------------------------
   import sys
   import os

   project_home = '/home/<username>/<REPO_NAME>/backend-py'
   if project_home not in sys.path:
       sys.path.insert(0, project_home)

   from dotenv import load_dotenv
   load_dotenv(os.path.join(project_home, '.env'))

   from a2wsgi import ASGIMiddleware
   from main import app as fastapi_app

   application = ASGIMiddleware(fastapi_app)
   -----------------------------------------------------------------------

G. MongoDB Atlas Network Access:
   Add 0.0.0.0/0 to your MongoDB Atlas IP Access List.

H. Click "Reload <username>.pythonanywhere.com" button in the Web tab.
